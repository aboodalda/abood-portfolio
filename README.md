# معرض أعمال عبود حسن — النسخة الأولية

## الملفات
- `index.html`: بنية الموقع ومحتواه.
- `style.css`: التصميم والألوان والتجاوب مع الشاشات.
- `script.js`: تصفية المشاريع وقائمة الهاتف.

## المعاينة محلياً
افتح `index.html` في المتصفح. يحتاج اتصالاً بالإنترنت لتحميل خط IBM Plex Sans Arabic من Google Fonts؛ وسيعمل بدونه بخط بديل.

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة إلى جذر مستودع `abood-portfolio`.
2. من إعدادات المستودع افتح **Pages**.
3. اختر **Deploy from a branch** ثم `main` والمجلد `/ (root)`، ثم Save.
4. بعد اكتمال النشر سيكون الرابط عادةً: `https://USERNAME.github.io/abood-portfolio/`.

## قبل النشر النهائي
- راجع رقم واتساب في قسم التواصل داخل `index.html`، واستبدله برقمك المهني إذا كان مختلفاً.
- أضف صوراً أصلية للمشاريع بدلاً من المعاينات المصممة بـCSS إن توفرت.
- افتح كل رابط مشروع وتأكد من أنه يعمل.
- راجع النصوص وأسماء المشاريع قبل مشاركة الرابط مع العملاء.
